# Contributing

Focused issues and pull requests are welcome.

1. Search existing issues.
2. Fork the repository and create a focused branch.
3. Run `npm ci`.
4. Add or update tests for behavior changes.
5. Run `npm test` and `npm run package`.
6. Add a Changeset for user-visible changes.

Never commit API keys, `.env`, prompts, responses, tool data, generated `out/`,
or VSIX files. By participating, you agree to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).
